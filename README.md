# Cosmic Destroyer

Browser sci-fi live-service: cinematic **ANGAR** hub, progression, cosmetics-only shop, loot capsules, skill tree, battle pass, and demo arena.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Features

- **Hangar**: live space backdrop, rotating 3D ship (Three.js), HUD with rank/level/loadout
- **Sections**: Ship, Weapons, Skills, Shop, Ranks, Inventory, Battle Pass
- **Equipment**: 8 slots, rarity tiers, stat aggregation
- **Cosmetics**: ship/laser/explosion skins, trails, banners (no pay-to-win)
- **Loadout**: pre-match weapon / ability / passive
- **Loot**: animated capsule opening
- **Daily quests** & **local save** (localStorage)

## Improvements baked in

- Cosmetics-only economy
- Reduced motion / mobile layout
- Onboarding tooltip
- Save persists in `localStorage`
- Haptic feedback on loot (where supported)
